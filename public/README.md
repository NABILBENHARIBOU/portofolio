# Public Assets

## CV / Resume

Pour activer le téléchargement de votre CV :

1. **Créez votre CV en PDF**
2. **Remplacez le fichier** `cv.pdf` dans ce dossier par votre CV réel
3. Le bouton "Download CV" sur votre portfolio téléchargera automatiquement ce fichier

Le fichier actuel `cv.pdf` est juste un placeholder et doit être remplacé par votre CV professionnel au format PDF.
